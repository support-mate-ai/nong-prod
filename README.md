# The NonG website (React + Vite)

## Environment
Copy `.env.example` to `.env` and set your Supabase project URL and anon key.
These are used by the waitlist form.

## Run
npm install
npm run dev      # development
npm run build    # production build

## Images
Put images in `public/`. Paths are defined in `src/data/images.js`
(currently `public/logo.png`, used in the header, hero card, mission block and favicon).
